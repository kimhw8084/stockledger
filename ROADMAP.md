# ROADMAP

## Current Phase

Phase 1: Local working prototype.

## Current Target

Prove the full local core loop:

Recipe -> Eye -> Evaluation -> Alert -> Decision -> Outcome

## Next Phases

1. Expand the first zero-cost provider adapter from price/history metrics into broader earnings, news, valuation, and quality coverage with visible freshness metadata.
2. Upgrade stock metric detail from inline expansion to stronger bottom-sheet / side-panel interaction while preserving the flat metric-board scan model.
3. Add editable outcome review flows and richer post-decision metrics backed by cached provider data.
4. Tighten the new six-workspace navigation shell with deeper drill-down stacks only where the stock, recipe, and alert surfaces prove they need another hierarchy layer.
5. Add explicit recipe editing, duplication, and version-preserving upgrade workflows.
